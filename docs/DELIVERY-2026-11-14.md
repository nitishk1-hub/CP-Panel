# Release candidate verification — 14 November 2026

The application regression suite passed 116 tests after replacing the legacy security UI and removing SSO/Vault runtime code. Test count decreased because tests for the removed modules were retired, while database/API, reverse-proxy lifecycle and persistent website/database-network tests were added. IDS startup also refreshes Docker interfaces before starting capture, covered by a regression test.

Stopped database instances remain manageable even if Docker retains an earlier healthy probe result.

Real disposable-container checks passed for PostgreSQL 17 and MariaDB 11.8: official-image digest resolution, private listener, isolated bridge, generated application login, table and row browsing, backup hashing, SQL restoration, password reset and stop. An independent PostgreSQL client container authenticated using the application account over its dedicated bridge. These are not comprehensive version/architecture qualifications or large-database recovery drills.

BunkerWeb's isolated fixture passed Off/Monitor/Block/Off checks using a constant local probe route; the malicious sample was blocked only in Block mode. Native Suricata compilation/startup and a checksum-valid loopback probe produced the expected alert, then the sensor was stopped. An isolated network namespace verified stable gateway bypass/redirect and response-rule ownership/timeouts without touching host policies. The installed provider was prepared in Off mode; capture is stopped while Off.

UI previews covered black dark mode, light navigation, collapsed gold icons, website categories/reverse-proxy filtering, database inventory and existing-container detection. Preview event data came from disposable local probes; no attack countries or external attacks were fabricated.

A pinned, network-isolated Semgrep scan completed over 84 files before final formatting, with no scanner errors and 497 heuristic findings (150 ERROR, 292 WARNING, 55 INFO). These labels are rule severities, not confirmed exploitable vulnerabilities. The new-module review covered HTML escaping, fixed shell snippets, validated arguments/identifiers, secret handling and resource ownership. Many hits flag existing HTML rendering and syntax patterns. The full set has not received independent adjudication and must not be described as clean. Detailed scan output stays private under var/security-review.

Runtime dependencies are separately audited during signed packaging. OS/container findings and independent security review remain separate readiness requirements. WAF/IDS is not a cure for unpatched packages, encrypted-traffic blind spots or host-root compromise. See WAF-IDS-CONSOLE.md for scope and availability fallback.

Graphify's code-only map uses local AST parsing and no indexing-model tokens. Its graph is a navigation aid, has extractor diagnostics and does not prove runtime behavior or security. Benchmark query reductions are estimates against reading the whole corpus, not verified account billing savings.
